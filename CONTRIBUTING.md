# Contributing to JPacManifest

Thank you for your interest in contributing to JPacManifest!

## Getting Started

Before contributing, please read the project's `README.md`, and `INSTALL.md`.

Make sure you have the required development tools installed and that you can successfully build the project and run its tests.

## Reporting Bugs

Please check the existing issues before reporting a bug.

When reporting a bug, include:

* A clear description of the problem
* Steps to reproduce it
* The expected behavior
* The actual behavior
* The JPacManifest version
* Your Java version
* Your operating system
* Any relevant error messages or stack traces

Please do not include sensitive information in bug reports.

## Suggesting Features

Feature suggestions are welcome.

Please expain:

* What you would like JPacManifest to do
* Why the feature would be useful
* Any relevant examples or use cases

## Pull Requests

Before submitting a pull request:

1. Make sure your changes are focuses on a specific bug fix, feature, or improvement.
2. Make sure the project builds successfully.
3. Run the test suite and make sure all tests pass.
4. Update documentation when necessary.
5. Write clear and descriptive commit messages.

Pull requests should explain what was changed and why.

## Code Style

Please follow the existing coding style and conventions used throughout the project.

Avoid unrelated changes in the same pull request.

## Tests

New functionality should include appropriate tests when practical.

Bug fixes should include a regression test when practical.
