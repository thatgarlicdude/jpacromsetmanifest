# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in JPacROMSetManifest, please do **not** report it through a public GitHub issue.

Instead, please report the vulnerability privately using GitHub's security reporting features.

Please include as much information as possible, including:

* The affected version of JPacROMSetManifest
* A description of the vulnerability
* Steps to reproduce the issue
* The potential impact
* Any relevant example files or code

Security vulnerabilities will be investigated and, when appropriate, addressed in a future release.
